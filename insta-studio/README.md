# Insta Studio(単発投稿ジェネレーター)

企業HPのURL・ブランドイメージ・掲載したい文言を入力すると、Instagram投稿を1本ぶん生成します。

**このアプリは独立しています。** 親フォルダの「採用アカウント構築スタジオ」とはコードも起動も別で、
片方を触ってももう片方には影響しません。ポート3002で動くため、同時に起動できます。

## 採用アカウント構築スタジオとの使い分け

| | このアプリ (Insta Studio) | 採用アカウント構築スタジオ |
|---|---|---|
| 単位 | **1投稿** | **アカウント1式** |
| 出力 | フィード / ストーリー / リールのいずれか | プロフィール + フィード9投稿 + ハイライト3種 + リール3本 |
| 使う場面 | 納品後の運用で1本ずつ追加する | 新規案件の初期構築(納品物一式) |

アカウントを新しく作るときは採用アカウント構築スタジオ、納品後に投稿を足していくときはこちらです。

## 生成できるもの

| コンテンツ | 出力 | 内容 |
|---|---|---|
| **フィード投稿** | PNG (1080×1350 / 4:5) ×4〜8枚 | カルーセル構成 + AI写真背景 + 6種類のテンプレート + キャプション + ハッシュタグ |
| **ストーリー** | PNG + MP4 (1080×1920) | 静止画4種類、および見出し→補足→CTAの3カットで構成する「動くストーリー」(約8秒) |
| **リール動画** | MP4 / H.264 (1080×1920) | 実写映像が主役の1本動画。冒頭フック + 下部テロップ + キャプション + 音楽提案 |

## 主な機能

- **MP4書き出し (WebCodecs)** — 1フレームずつ正確に描画してH.264/MP4にエンコード。非対応ブラウザでは自動的にWebMへ
- **AI Bロール動画 (Sora)** — リール背景をシーンごとにカット割りで生成。毎回ランダムなカメラワークとライティングが付く
- **複数素材のアップロード** — 写真は最大20枚、動画は最大12本。フィードのスライドごと・リールのシーンごとに自動配分され、1枚ずつ差し替えできる
- **採用アカウントモード** — 投稿の型を12種類(社員インタビュー / 社員の1日 / 数字で見る会社 など)から選べる
- **ブランドキット保存** — ロゴ・HP URL・ブランド説明をブラウザに保存

## セットアップ

このフォルダの中で実行してください(親フォルダとは別に依存関係を入れます)。

```bash
cd insta-studio
npm install
cp .env.example .env
# .env に ANTHROPIC_API_KEY を設定(必須)
# OPENAI_API_KEY を足すと AI写真背景 と Sora動画が使えます
npm run dev
```

http://localhost:3002 を開いてください。

## Windows でダブルクリック起動する

初回のセットアップが済んでいれば、以降は **`start-insta.bat` をダブルクリック**するだけです。
黒い画面が出たままになりますが、それがサーバー本体なので開いたままにしてください。

## 技術構成

- Next.js 15 (App Router) + TypeScript + React 19
- Anthropic TypeScript SDK — 構造化出力でコンテンツプランを生成
- Canvas API — 日本語の文字組みを描画(画像生成AIにありがちな文字化けが起きません)
- WebCodecs + mp4-muxer — フレーム正確なMP4書き出し
