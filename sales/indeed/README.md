# Indeed運用代行・採用支援 — リストアップとフォーム営業

新サービス「Indeed運用代行・採用支援」専用の営業リストと、フォーム営業を回すための一式です。

```
sales/indeed/
├── data/
│   ├── raw-postings.tsv   ← Indeedで観測した求人（1行=1求人）。リストの原材料
│   └── targets.csv        ← 企業単位に集約・スコアリングした営業リスト（成果物）
├── templates/
│   └── messages.mjs       ← 業種別＋区分別のフォーム営業文面
├── scripts/
│   ├── classify.mjs       ← 区分判定（地方企業/地方派遣/全国大手/全国大手派遣/単店舗）
│   ├── build-list.mjs     ← raw-postings.tsv → targets.csv
│   └── build-console.mjs  ← targets.csv → console.html
├── console.html           ← ブラウザで開く営業コンソール（生成物）
└── playbook.md            ← 営業の進め方・日程調整・返信対応
```

## 使い方

```bash
node sales/indeed/scripts/build-list.mjs      # リストを再集計
node sales/indeed/scripts/build-console.mjs   # コンソールを再生成
open sales/indeed/console.html                # ブラウザで開く（Linuxなら xdg-open）
```

コンソールを開いたら、上部に自社名・担当者名・電話・メールを一度入力してください。
以降すべての企業の文面に自動で反映され、ブラウザに保存されます。

企業を選ぶと「件名 / 本文 / 短縮版」が生成されるので、コピーして問い合わせフォームに貼るだけです。
「問い合わせ先を検索」ボタンで、その企業の問い合わせページをGoogle検索できます。
送信したら「送信済みにする」を押すと、リストから消えて次の企業に進めます。

## スコアリングの考え方

Indeedの出稿額は外から直接は見えません。そこで**額と相関する観測可能な指標**を積み上げてスコア化しています。

| 指標 | 配点 | 理由 |
|---|---|---|
| 同時掲載件数 | ×10 | スポンサー枠の数に直結する最重要指標 |
| 拠点数（市区町村） | ×8 | 多店舗展開＝採用ニーズが恒常的 |
| 複数都道府県 | +15 | 県をまたぐ規模がある |
| 直近90日以内の掲載 | +15 | いま現在アクティブな予算がある |
| 掲載期間90日以上 | +20 | **通年採用の証拠**（今回の要件の核） |
| 掲載期間240日以上 | +10 | ほぼ1年通して出稿している |
| 業種係数 | ×1.2 | アミューズメント・介護・運送・飲食・警備・派遣は出稿単価が構造的に高い |

「推定月額出稿」は `掲載件数 + 拠点数` から算出した**目安**です。地方のスポンサー求人1枠あたり月2〜5万円という前提を置いています。実額ではないので、商談では断定しないでください。

**派遣会社は推定を1段階引き上げています。** 1社で数十〜数百本の求人を常時走らせるのが普通で、検索で観測できる件数は氷山の一角だからです。

### 重要な注意：C評価は「見込みが薄い」という意味ではない

Indeedの検索は1クエリあたり10件しか返らないため、**1回のクエリでしか観測できていない企業は、実際にはもっと出稿していても掲載1件として記録されます**。C評価の多くはこのサンプリング上の制約によるものです。

同じ企業を別の職種・別の市区町村で追加検索すると件数が増え、B・Aに昇格します。リストを育てる作業とは、実質これのことです。

## リストを増やす

「とにかくたくさん」増やすための手順です。Indeedを検索して、結果を `data/raw-postings.tsv` にタブ区切りで追記し、ビルドし直します。

```
企業名	都道府県	市区町村	職種カテゴリ	掲載日	求人URL
```

職種カテゴリは既存の13種から選んでください：
飲食 / 介護 / 小売 / 建設 / 運送 / 自動車 / アミューズメント / 美容 / 保育 / 製造 / ホテル / 警備 / 派遣

**カテゴリを「派遣」にすると、社名にかかわらず人材会社として分類され、派遣向けの文面が当たります。**

### 未カバーの掛け合わせ

いま入っているのは「都道府県 × 業種」の組み合わせのごく一部です。以下がまだ空いています。

- **未着手の県**：山梨・奈良・徳島
- **派遣会社の深掘り**：地方の人材会社は狙い目です。「軽作業 派遣」「工場 派遣 寮完備」「人材派遣 コーディネーター」などで各県を叩くと出てきます。ホットスタッフのように地域ごとに別法人になっているグループは、法人単位で決裁できるため特に当たりやすい相手です
- **既存県の未着手業種**：たとえば北海道は飲食・アミューズメント・介護しか叩いていないので、運送・小売・ホテル・建設が丸ごと空いています。41道府県 × 13業種 = 533通りのうち、実施済みは60通りです
- **深掘り**：S・A評価の企業名で直接検索すると、その企業の他の求人が出てきます。件数が積み上がってスコアが上がり、提案の具体性も増します

### 規模の小さい企業へ広げるとき

まず地方ローカルチェーンを優先し、枯れてきたら小規模企業へ、という方針に沿っています。小規模側へ広げるときは、検索語を「店長候補」「施工管理」といった**幹部・有資格者向けの語**から、「ホールスタッフ」「軽作業」といった**時給職の語**に寄せると、単店舗・小規模の事業者が多く出てきます。

`build-list.mjs` は既存の `targets.csv` から手入力列を読み戻してから書き直すので、リサーチを追加しても書き込んだ内容は失われません。

## 文面について

`templates/messages.mjs` にテンプレートがあります。設計の考え方は [playbook.md](./playbook.md) を参照してください。

文面は**業種別（13種）と区分別の二段構え**です。区分別の提案（`SEGMENT_PITCH`）がある場合はそちらが優先されます。派遣会社と全国大手には、そもそも当てるべき話が違うためです。

| 区分 | 何を言うか |
|---|---|
| 地方企業 | 業種特有の採用課題 → 運用代行フル |
| 地方派遣・全国大手派遣 | 案件数が多すぎて原稿と停止判断が追いつかない問題 → 大量求人の運用と原稿量産 |
| 全国大手 | 全社平均に埋もれるエリア別の単価悪化 → 1エリアだけの試験導入 |

文面中の実績部分は、コンソールの「同業実績」欄に入力したときだけ本文に現れます。**空欄なら実績には一切触れない文面が出力されます。** 事実でない実績を書かないための仕様なので、埋めるときは実データだけを入れてください。
