# フォーム営業プレイブック（Indeed運用代行・採用支援）

## 1. この文面がなぜこの構成なのか

フォーム営業は、読まれるかどうかが**冒頭2行**でほぼ決まります。挨拶とサービス紹介から入った時点で、担当者は営業テンプレだと判断して読むのをやめます。

そこで本テンプレートは、冒頭を必ず**その企業のIndeed求人を実際に見た事実**から書き出します。

> Indeed上で御社の求人を拝見し、上浮穴郡・喜多郡・松山市など8拠点で8件の募集を掲載されていることに注目しました。掲載開始から107日にわたって継続的に出稿されており、単発の欠員補充ではなく通年での採用に取り組まれていると拝察しています。

エリア名・件数・掲載期間はすべて `targets.csv` の実データです。受け取った側からすると「自社のことを調べたうえで書いている」ことが1行目で分かります。これがこのリストの最大の武器で、業種別にテンプレを分けている理由でもあります。

構成は以下の6ブロックです。

1. **観測事実** — 誰にでも送れる文章ではないことを最初に示す
2. **業種特有の課題提起** — 他社が指摘してこない角度を選ぶ
3. **提案（3点）** — 抽象論ではなく具体的な打ち手
4. **実績** — 実データがある場合のみ表示（空欄なら出ない）
5. **無料診断のオファー** — 発注前提でない、断りやすい入口
6. **日程調整** — 候補日3つ・所要時間明記・代替の逃げ道つき

## 2. 日程調整の設計

返信率を落とす最大の要因は「相手に考えさせること」です。次の4点で相手の負担を消しています。

- **候補日を3つ、こちらから出す。** 「ご都合のよい日時をお知らせください」は相手にカレンダーを開かせる作業を発生させます。生成される候補日は送信日の3営業日後から平日3日ぶんが自動で入ります
- **時間帯は10:00〜17:00と幅で出す。** ピンポイントで出すと外れたときに再調整になります
- **所要時間を明記する（20〜30分）。** 何分拘束されるか分からない打ち合わせは後回しにされます
- **「資料だけでも可」の逃げ道を必ず残す。** 商談に抵抗がある相手でも返信でき、資料送付から関係が始まります

候補日は文面生成時の日付を基準に計算されるので、**生成したその日に送ってください。** 数日寝かせると候補日が過去になります。

## 3. 無料診断を入口にする理由

現時点で自社の実績を並べられない場合でも、この文面はそのまま機能します。「御社の現在の求人を見て、どの職種にいくら使われ、どこに無駄が出ているかを診断する」というオファーは、

- 相手にとって具体的な持ち帰り価値がある
- 発注判断を求めていないので断る理由がない
- こちらの実力を証明する場になる（提案が的確なら、そのまま受注に繋がる）

という三方よしの入口です。実績が貯まったらコンソールの「同業実績」欄に入れてください。文面の説得力が一段上がります。

**やってはいけないこと：** 実績欄に事実でない数字を入れること。初回商談で必ず突っ込まれます。空欄で送るほうが安全です。

## 4. 送信前チェック

| 確認項目 | 理由 |
|---|---|
| 「営業お断り」の記載がないか | 記載があるフォームには送らない。クレームと悪評のリスクに見合いません |
| 法人名が正しいか | 店舗名・屋号で拾った行があります。運営元を調べてから送ってください |
| 求人がまだ生きているか | 「求人を拝見しました」と書く以上、掲載が終わっていたら台無しです。コンソールの「Indeedの求人を確認」で確認できます |
| 「注意」列が空か | 「運営元の法人名を要確認」なら親会社を調べてから。「同名別法人の合算の可能性」なら、別会社の実績を1社に混ぜたまま送ることになるので必ず確認を |
| 差出人情報が埋まっているか | `{{担当者名}}` のまま送るのが最悪の事故です。コンソール上部で必ず入力してください |

## 5. 相手の区分別のアプローチ

文面は区分に応じて自動で切り替わるので、送る側で書き分ける必要はありません。ただし相手の事情は理解しておいてください。

- **地方企業** — 業種特有の採用課題から入り、運用代行をフルで提案します。優先度S→A→Bの順に消化してください
- **地方派遣** — 狙い目です。1社で数十〜数百本の求人を常時走らせており、Indeedの出稿額は業種を問わず大きくなります。社内に運用担当がいても案件追加とスタッフ対応で手一杯なのが実情なので、「運用を奪う」ではなく「**手が回っていない部分を引き受ける**」という立て付けにしてあります。ホットスタッフのように地域ごとに別法人になっているグループは、法人単位で決裁できるぶん通りやすい相手です
- **全国大手派遣** — 出稿額は最大級ですが全社提案は決裁に乗りません。苦戦している支店を1つ挙げてもらう形で入ります
- **全国大手** — 代理店が入っている確率が高く本部決裁です。全社の切り替えではなく「1エリアだけ試す」提案にしてあります。断られても、エリア担当者との接点が残ります
- **単店舗** — 出稿額が小さく優先度は下がりますが、複数店舗を持つオーナーであることもあります。他の店舗を検索して規模を確認してから判断してください

## 6. 返信が来たあと

- **日程が返ってきた** — 即座に確定の返信を送り、その場でオンライン会議のURLを発行して添付します。日をまたぐと熱が冷めます
- **「資料だけ」と返ってきた** — 約束どおり診断結果と資料を送ります。ここで営業をかけ直さないこと。診断の質そのものが次のアポを作ります
- **返信なし** — フォーム営業は初回で返らないのが通常です。1〜2週間後、**別の切り口**で1回だけ追う。同じ文面の再送は逆効果です。追いかけの切り口としては、初回送信後に相手の求人がどう変化したか（増えた／止まった）に触れると自然です
- **断り** — `targets.csv` のステータスに記録して二度と送らない。リストの信用を守るほうが1件の受注より価値があります

## 7. 記録

コンソールの「送信済み」はブラウザのlocalStorageに保存されます。ブラウザを変えると引き継がれないので、区切りのいいところで「送信記録をCSV出力」を押し、`targets.csv` のステータス列に反映してください。`build-list.mjs` を再実行しても手入力列は保持されます。
