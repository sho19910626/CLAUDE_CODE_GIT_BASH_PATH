## やること2: フランチャイズ運営会社の特定（本命）

### なぜ狙うのか

- 本部はブランドを配るが**採用は配らない**。Indeed出稿は各FC運営会社の自腹
- 社内に採用担当がおらず、**本部支給のテンプレ原稿を流用**するだけなので埋もれる
- 複数ブランドを持つことが多く、職種もエリアもバラバラで予算配分が破綻しやすい
- 社長かエリアマネージャーで決裁が終わる

### 判別方法

Indeedの**求人タイトルにはブランド名**、**Company欄には運営会社名**が入る。
この2つが食い違っていればFC運営とみてよい。

> 「ラ・ムー 宇城店の精肉コーナースタッフ」→ 運営: マミーズ株式会社
> 「牛角のホール・キッチンスタッフ」→ 運営: 株式会社EXCEL

### 実装すること

1. **`raw-postings.tsv` に `ブランド` 列を追加**
   いま求人タイトルを保存していないのが穴。収集時にタイトルからブランド名を抜いて記録する。
   既存1,145行は空欄のままでよい（後方互換のため列は末尾に追加し、欠損を許容する）

2. **`classify.mjs` にFC判定を追加**
   ブランド名 ≠ 企業名 なら `FC運営` フラグを立てる。区分とは別の独立したフラグにする
   （FC運営かつ地方企業、という組み合わせがありうるため）

3. **ブランド名で逆引き検索**
   「業務スーパー」で検索すると、それを運営するFC会社がCompany欄にずらりと出る。
   FC運営会社を狙い撃ちで集める最も効率的な方法

   狙い目ブランド:
   - 小売: 業務スーパー / ラ・ムー / セブン-イレブン / ローソン / ファミリーマート
   - 飲食: ほっともっと / 牛角 / 鳥貴族 / コメダ珈琲店 / 大戸屋 / リンガーハット / ピザーラ
   - 美容: QBハウス / サンキューカット / HAIR SALON IWASAKI
   - 学習塾: 明光義塾 / ITTO個別指導学院 / 個別教室のトライ ← **リストに1社もない**
   - その他: オートバックス / カーブス / セカンドストリート / おたからや ← **買取店も未着手**

4. **FC運営会社向けの文面を `messages.mjs` に追加**
   `SEGMENT_PITCH` と同じ仕組みで、FCフラグが立っていたらこちらを優先する。

   突く角度:
   - 本部支給の原稿をそのまま使っているため、地域の労働市場に合っていない
   - 同じブランドの他店・他エリアと同じ文面で戦っており、検索結果で差がつかない
   - 複数ブランドを運営している場合、ブランドをまたいだ予算配分が誰も見ていない

   オファー: 「本部支給の原稿と、御社の商圏で実際に応募が集まっている求人との差分を無料で診断」
