# Insta Studio — 企業向け Instagram コンテンツ自動生成アプリ

企業HPのURL・企業イメージ・掲載したい文言を入力するだけで、Instagram運用代行に見劣りしないクオリティの投稿コンテンツを自動生成するWebアプリです。

## 生成できるコンテンツ

| コンテンツ | 出力 | 内容 |
|---|---|---|
| **フィード投稿** | PNG (1080×1350 / 4:5) ×4〜5枚 | カルーセル構成(表紙→ポイント解説→CTA) + AI写真背景 + 6種類のテンプレート + キャプション + ハッシュタグ |
| **ストーリー** | PNG (1080×1920) | AI写真背景 + 3種類のデザインテンプレート + CTAボタン |
| **リール動画** | WebM (1080×1920) | フック→ポイント→CTA構成のアニメーション動画(AI写真背景対応) + キャプション + 音楽提案 |

## 仕組み

1. **サイト分析** — 入力された企業HPをサーバー側で取得し、タイトル・説明・本文テキストを抽出
2. **AI設計** — Claude (claude-opus-4-8) がブランド分析を行い、配色・フォント・テンプレート選定・コピーライティング・キャプション・ハッシュタグ戦略・背景画像プロンプトまでを構造化データとして設計
3. **AI背景生成(任意)** — OpenAI の画像生成API (gpt-image-1) でブランドに合わせた商業写真クオリティの背景を生成
4. **レンダリング** — ブラウザのCanvas APIで背景の上に日本語の文字組みを重ね、画像・動画としてエクスポート

日本語テキストはCanvasで描画するため、画像生成AIにありがちな**文字化け・崩れが起きません**。Anthropic APIキーのみでも動作し(テンプレート背景)、OpenAI APIキーを追加すると「✨ AI写真」背景が使えます。

## セットアップ

```bash
# 1. 依存関係のインストール
npm install

# 2. 環境変数の設定
cp .env.example .env
# .env に APIキーを設定
# ANTHROPIC_API_KEY=sk-ant-...  (必須)
# OPENAI_API_KEY=sk-...          (任意: AI写真背景を使う場合)

# 3. 開発サーバーの起動
npm run dev
```

http://localhost:3000 を開き、フォームに入力して「コンテンツを生成する」を押してください。

## 使い方のコツ

- **企業HPのURL**: トップページのURLを入れると、AIが事業内容・トーンを自動分析します
- **企業イメージ**: ターゲット層・ブランドの雰囲気・強みを書くほど精度が上がります
- **文言**: キャンペーン情報や期限など、画像に必ず入れたい内容を書いてください
- 生成後もテンプレートを切り替えてデザインの候補を比較できます
- **「✨ AI写真」テンプレート**を選ぶと、ブランドに合わせた写真背景をその場で生成します(OpenAI APIキーが必要。1枚あたり数円〜数十円の従量課金)
- リール動画は「AI写真背景」に切り替えるとKen Burns効果(ゆっくりズーム)付きの写真背景になります
- リール動画はWebM形式で書き出されます。Instagram投稿時はMP4への変換を推奨します
- OpenAIの新しい画像モデルが出たら `.env` の `OPENAI_IMAGE_MODEL` を変えるだけで切り替えられます

## 技術構成

- [Next.js 15](https://nextjs.org/) (App Router) + TypeScript + React 19
- [Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript) — 構造化出力 (JSON Schema) でコンテンツプランを生成
- Canvas API — 画像テンプレートのレンダリング
- MediaRecorder API — リール動画のWebM書き出し
- Google Fonts (Noto Sans JP / Noto Serif JP / M PLUS Rounded 1c)
