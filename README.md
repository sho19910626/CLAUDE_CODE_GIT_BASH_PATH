# 企業向けコンテンツ生成スタジオ

AIで企業のマーケティング・採用コンテンツを設計するWebアプリです。2つのツールが入っています。

| ツール | パス | 用途 |
|---|---|---|
| **Indeed 提案スタジオ** | `/indeed` | ヒアリング内容から「棲み分け」戦略・キャッチコピー・撮影指示・Indeed掲載原稿を一括生成 |
| **営業コンソール** | `/console.html` | フォーム営業のターゲットリストと、企業ごとの営業文面の生成 |
| **Insta Studio** | `/` | 企業向けInstagramのフィード画像・ストーリー・リール動画を自動生成 |
| **動画編集スタジオ** | `/video` | サービス説明動画から、SNS用ショート動画と3〜5分の本編を自動編集 |

営業コンソールで商談化した企業は、**「提案スタジオへ引き継ぐ」**を押すと、企業名・業種・勤務地・Indeedの掲載状況が入った状態で提案スタジオが開きます。同じサーバーに同居しているため、コピーや貼り付けは要りません。

# Indeed 提案スタジオ (`/indeed`)

お客様へのヒアリング内容を入力すると、Indeedに掲載する求人の提案一式を出力します。
**アルバイト・パート / 正社員(中途) / 正社員(新卒) / 契約・派遣・業務委託** に対応し、雇用形態ごとに訴求軸と原稿の書き方が切り替わります。

## 核となる考え方 — 「棲み分け」

このツールは応募数を増やすためのものではありません。**勝てない土俵から降りて、自社が一番になれる土俵に移る**ための求人を設計します。設計思想の原典として、JA(農協)の採用事例をAIに教え込んでいます。

> JAは「金融機関に興味がある人材」を採ろうとしていた。しかし金融志望者は都市銀行→地方銀行→信用金庫と受けて、最後の滑り止めにJAを受ける。つまりJAは競合すべてに落ちた人を採用していた。
> 実際に活躍している職員を観察すると、彼らは「金融が好きな人」ではなく「農家のおばあちゃんと縁側でお茶を飲むのが好きな人懐っこい人」だった。
> そこでキャッチコピーを「おばあちゃんと縁側でお茶を飲む仕事です」に変え、原付であぜ道を走る職員が縁側でお茶を飲む写真を載せた。すると応募者の質が一変し、「金融志望者の最下層」ではなく「人懐っこい人材の最上位層」を採れるようになった。

この構造を踏襲し、AIは次の手順で提案を組み立てます。

1. いま戦っている土俵を特定し、その中で何番目なのかを忖度せず言語化する
2. ヒアリングにある「活躍している人の特徴」「エピソード」から、その会社にしか言えない**仕事の再定義**を導く
3. 新しい土俵を宣言し、**あえて来なくていい人**まで明言する
4. 職種名・キャッチコピー・写真・原稿本文・応募時の質問まで、すべてを新しい定義に揃える

## 出力される提案

| タブ | 内容 |
|---|---|
| **① 棲み分け戦略** | 現状分析(戦っている土俵・立ち位置・勝てない理由・放置した場合のリスク) / 仕事の再定義 / 新しい土俵 / ターゲット人材の人物像と検索行動 / 棲み分けの根拠 / 切り捨てる人 |
| **② 職種名・コピー** | Indeed職種名の推奨案+別案3つ+埋め込む検索キーワード / キャッチコピー5案(情景型・逆説型・引用型・数字型・呼びかけ型)と、それぞれの狙いと使いどころ |
| **③ ビジュアル** | メインカットの撮影指示書(シーン・被写体・構図・光・トーン) / 掲載カットリスト4〜6枚と各カットの役割 / 撮ってはいけない写真 / AI画像生成(OpenAI APIキー設定時) |
| **④ 掲載原稿** | Indeedにそのまま貼れる完成原稿(職種名・仕事内容600〜1000字・訴求ポイント・1日の流れ・応募資格・募集要項・選考フロー・FAQ)。全文コピー / .txtダウンロード |
| **⑤ 運用・チェック** | KPI設計 / スポンサー予算の考え方 / A/Bテスト案 / 運用のポイント / 応募時に聞くべき質問 / 掲載前の法令チェック |

提案書全体は Markdown でコピー・ダウンロードでき、そのまま顧客への提案資料になります。

## ヒアリング項目

**★印の2項目が提案の質を決めます。** 棲み分けは活躍者の観察からしか導けないためです。

- 基本情報 — 企業名 / 企業HP・採用サイトURL(内容を自動で読み取ります) / 事業内容 / 募集職種 / 勤務地
- **★ 棲み分けの材料** — 実際に活躍している人の特徴 / 活躍している人の具体的なエピソード / すぐ辞めた人の特徴 / 職場の雰囲気
- 採用の現状 — 採用競合 / 現在の採用課題 / これまでの訴求内容 / 採用人数・時期・予算
- 募集条件 — 給与 / 勤務時間・シフト / 休日 / 福利厚生 / 応募条件 / 選考フロー
- 職場の写真(最大3枚・任意) — AIが空気感を読み取り、棲み分けと撮影指示に反映します

未入力の項目はAIが業種から補完しますが、**給与や数字は捏造せず「面談時にご案内します」と書きます**。追加でヒアリングすべき事項は⑤タブの「掲載前チェック」に出力されます。

フォーム下部の「サンプル(JA事例)を入力してみる」を押すと、上記のJA事例がヒアリングシートに入り、棲み分けがどう機能するかを試せます。

## Indeedというメディアへの最適化(AIに組み込み済み)

- Indeedは検索エンジン型のため、職種名の先頭には**検索される一般名詞**を置き、その後ろに棲み分けを表す一言を足す
- 求職者が見るのは【職種名 → 給与・勤務地 → 画像 → 仕事内容の冒頭3行】の順。ここで離脱が決まる前提で原稿を組む
- 8割以上がスマートフォン閲覧。1文を短く、段落を細かく、空行を多めに
- 「急募!!」「稼げる!」などの煽り表現・記号の羅列は品質評価を下げるため使わない
- 職業安定法・男女雇用機会均等法・雇用対策法により、年齢・性別・国籍を限定する表現を書かない。「若手歓迎」「主婦歓迎」「女性活躍中」も避け、事実の記述(「入社1〜3年目が中心です」)に置き換える

# Insta Studio (`/`)

企業HPのURL・企業イメージ・掲載したい文言を入力するだけで、Instagram運用代行に見劣りしないクオリティの投稿コンテンツを自動生成します。

## 生成できるコンテンツ

| コンテンツ | 出力 | 内容 |
|---|---|---|
| **フィード投稿** | PNG (1080×1350 / 4:5) ×4〜8枚 | カルーセル構成(表紙→ポイント解説→CTA) + AI写真背景 + 6種類のテンプレート + キャプション + ハッシュタグ |
| **ストーリー** | PNG + MP4 (1080×1920) | 静止画4種類のテンプレート、および見出し→補足→CTAの3カットで構成する「動くストーリー」(約8秒) |
| **リール動画** | MP4 / H.264 (1080×1920) | 実写映像が主役の1本動画。冒頭フック + 下部テロップのプロ仕様レイアウト + キャプション + 音楽提案 |

### リールとストーリーの使い分け

Instagramでの役割が違うため、見せ方を作り分けています。

- **リール** — 発見タブで新規リーチを取るための動画。**映像が主役**で、テキストは冒頭のフックと下部テロップ(POINTチップ + 見出し + 字幕)だけに絞ります。背景は Sora のAI動画やアップロード動画をそのままフルに見せ、暗幕(スクリム)も薄くしています
- **ストーリー** — 既存フォロワー向けの24時間限定コンテンツ。**テキストが主役**で、1文字ずつ現れるキネティックタイポグラフィ、シーン切替のワイプ、上部プログレスバーといったスライド演出を使います。静止画と動画の両方を書き出せます

## プロ品質のための機能

- **MP4書き出し (WebCodecs)**: リールは1フレームずつ正確に描画してH.264/MP4にエンコード。フレーム落ちがなく、そのままInstagramに投稿できます(非対応ブラウザでは自動的にWebMへフォールバック)
- **AI Bロール動画 (Sora)**: リール背景として、OpenAI Sora がブランドに合わせたCM風の実写映像を生成。2つの構成から選べます
  - **シーンごとにカット割り(推奨)**: フック→ポイント→CTAの各シーンが別々の映像に切り替わる、テレビCMと同じカット編集(4秒×シーン数、約$0.4×シーン数)
  - **1本の映像**: 8秒1本を全シーン共通の背景に(約$0.8)
  - 毎回ランダムなカメラワーク(ドリーイン/トラッキング/俯瞰など)とライティング(ゴールデンアワー/ハイキーなど)が付与され、**作り直すたびに違う映像**になります。`OPENAI_VIDEO_MODEL=sora-2-pro` でさらに高品質な映像も選択可(料金約3倍)
- **ブランドロゴ**: 透過PNGをアップロードすると全テンプレートの定位置に自動配置
- **ブランドキット保存**: ロゴ・HP URL・ブランド説明をブラウザに保存し、次回起動時に自動復元
- **モーションデザイン**: 1文字ずつ現れるキネティックタイポグラフィ、シーン切替のワイプトランジション、浮遊パーティクル、フィルム風ビネット、CTAボタンのパルスなど

## 採用アカウントモード

「アカウントの目的」を **👥 採用(公式採用アカウント)** に切り替えると、企業の公式採用アカウントの運用作法に沿った設計に変わります。

**投稿の型を12種類から選べます** — 社員インタビュー / 社員の1日 / 数字で見る会社 / 福利厚生・制度 / オフィス・職場紹介 / 選考フロー / 求職者からのQ&A / 職種・仕事内容 / 新入社員・内定者の声 / 社風・カルチャー / 代表・先輩メッセージ / 募集要項

型に応じてカルーセルの構成そのものが変わります。「社員の1日」なら1枚1時刻の6〜8枚構成、「選考フロー」なら1枚1ステップ、「数字で見る会社」なら1枚1数字といった具合です。

**採用アカウント向けの設計指針**(AIに組み込み済み)

- 主役は「人」。会社の実績や設備ではなく、そこで働く個人の顔・言葉・1日を描く
- 求職者が本当に知りたい6項目(仕事内容 / 1日の流れ / 一緒に働く人 / 給与・休日・残業の実態 / キャリア / 選考の進み方)に正面から答える
- 「アットホームな職場」「風通しがいい」「若手が活躍」といった、求職者に最も警戒される常套句を使わず、それを証明する事実と数字に置き換える
- 年齢・性別・国籍を限定する表現を書かない(職業安定法・男女雇用機会均等法への配慮)。「若手歓迎」「女性活躍中」も自動的に避けます
- ハッシュタグに勤務地の地名タグを必ず含める(求職者の検索行動に直結するため)
- 背景画像は商品写真ではなく「働く人と職場」を、日本のオフィス・現場として描写する

**追加の入力欄**(すべて任意・埋めるほど具体的になります): 対象 / 募集職種 / 勤務地 / 会社の数字 / 福利厚生・制度 / 社員の声・エピソード / 求める人物像 / 選考フロー / 応募導線

## 参考素材のアップロード(任意)

- **写真(最大3枚)**: AIが視覚分析してコピー・配色・背景に反映。1枚目はフィード/ストーリー/リールの背景としてそのまま使うことも、OpenAIの画像編集APIで「写真を参考にしたAI背景」に仕上げることもできます
- **動画(1本)**: リール動画の背景として実写映像を使用できます(テキストアニメーションを自動合成)。動画はサーバーに送信されず、ブラウザ内でのみ処理されます

## 仕組み

1. **サイト分析** — 入力された企業HPをサーバー側で取得し、タイトル・説明・本文テキストを抽出
2. **AI設計** — Claude (claude-opus-4-8) がブランド分析を行い、配色・フォント・テンプレート選定・コピーライティング・キャプション・ハッシュタグ戦略・背景画像プロンプトまでを構造化データとして設計
3. **AI背景生成(任意)** — OpenAI の画像生成API (**gpt-image-2**) でブランドに合わせた商業写真クオリティの背景を生成。Canvasの実サイズに合わせて 4:5 は 1088×1360、9:16 は 1088×1920 のネイティブ解像度で受け取るため、拡大による劣化がありません
4. **レンダリング** — ブラウザのCanvas APIで背景の上に日本語の文字組みを重ね、画像・動画としてエクスポート

日本語テキストはCanvasで描画するため、画像生成AIにありがちな**文字化け・崩れが起きません**。Anthropic APIキーのみでも動作し(テンプレート背景)、OpenAI APIキーを追加すると「✨ AI写真」背景が使えます。

# 動画編集スタジオ (`/video`)

**すでに撮影・録画済みのサービス説明動画**をアップロードすると、話している内容を聞き取り、
**SNS用のショート動画(9:16)** と **商談・サイト掲載用の本編(16:9 / 3〜5分)** の2本を設計・書き出しします。

他の2ツールが「ゼロから作る」のに対し、こちらは**素材を編集する**ツールです。

## 処理の流れ

```
素材動画 ─→ 文字起こし ─→ 内容分析 ─→ 編集台本(EDL) ─→ 画面で手直し ─→ MP4書き出し
          (Whisper)     (Claude)      (Claude)         (人)          (ffmpeg)
```

1. **文字起こし** — OpenAI Whisper で、秒単位のタイムスタンプ付きで書き起こす
2. **内容分析** — Claude が「何を・誰に伝える動画か」「素材に実在する数字・事実」を整理する
3. **構成設計** — ショート版と本編を**別々の商品として**設計する。目的が違うため、カットの選び方もテロップの入れ方も変える
4. **手直し** — カットの採否 / 開始・終了秒 / テロップ文言 / 並び順を画面で直す
5. **書き出し** — サーバー側の ffmpeg が、テロップを焼き込んだ MP4 を生成する

## ショート版と本編の作り分け(AIに組み込み済み)

| | ショート動画 | 本編 |
|---|---|---|
| 出力 | 9:16 / 1080×1920 | 16:9 / 1920×1080 |
| 尺 | 25〜59秒 | 3〜5分 |
| 用途 | リール・TikTok・Shorts での新規リーチ | 商談・サイト掲載・営業メール |
| 冒頭 | 1.5秒で結論か課題を出す。前置き禁止 | 課題提起から入り、順を追って納得させる |
| 1カット | 2〜5秒(8〜14カット) | 6〜20秒(15〜30カット) |
| 大テロップ | ほぼ全カット(音を出さずに観られる前提) | 章の先頭のカットだけ |
| 字幕 | 補足が要るカットだけ | 原則すべてのカット |

## 編集の品質のために組み込んでいるルール

- **素材に無い事実を書かない** — 数字・実績・固有名詞は、文字起こしに実在したものだけをテロップに使う。無ければ数字を入れずに書く
- **言い淀み・言い直し・沈黙は使わない** — 「えー」「あのー」が入る区間はカットごと外す
- **カットの境目は文の切れ目に置く** — 単語や文節の途中で切らない
- **テロップは映像の説明をしない** — 「パソコンを操作している」ではなく「登録は3クリックで完了」。映像だけでは伝わらない要点を言い切る
- **改行はテレビのテロップ品質で** — 文節の切れ目のみ、行頭に助詞を置かない、行の文字数を揃える
- **並び順は素材の時系列に縛られない** — 伝わる順に組み替える。素材が複数あるときはカットごとに最適な1本を選ぶ
- **音量を配信基準に揃える** — 書き出しの最後に loudnorm で -16 LUFS に正規化する

## 音声の扱い(2通り)

| モード | 内容 | 向いている場面 |
|---|---|---|
| **元の音声を使う** | 話者の声をそのまま残し、良い区間だけを繋ぐ | 最も自然。人が話している素材はこちらが基本 |
| **AIナレーションに差し替える** | OpenAI TTS が台本を読み上げ、その長さに合わせて映像の尺を決める | 話者の声質が揃わない / 無音の画面録画 / 台本を書き直したいとき |

AIナレーションでは、**ナレーションの長さが正**になります。素材の残り尺が足りないカットは最後のフレームを止めて伸ばすため、
尺が合わずに映像が途切れることはありません。

## 縦横比が変わるときの2つの方式

横向きの素材からショート動画(縦)を作るときは、どちらかを選びます。

- **中央を切り抜く (crop)** — 人物・実写向き。画面いっぱいに使えるが、左右が切れる
- **全体を残す (blur)** — **画面録画・デモ動画向き**。元映像を丸ごと中央に収め、上下の余白は同じ映像をぼかして埋める。UIや文字が切れない

## 入力できるもの

- **素材動画(複数可)** — mp4 / mov / webm / mkv など。1本の説明動画でも、撮影クリップを何本入れても構いません
- **案件情報** — 企業名 / サービス名 / 企業HP(内容を自動で読み取ります) / 届けたい相手 / 必ず伝えたいこと / CTA / トーンの希望
- **BGM** — `public/bgm/` に置いた**ライブラリから選ぶ**か、案件ごとに個別の音源をアップロードする(下記)
- **ロゴ(任意)** — 透過PNG。全カットの右上に自動配置します

## BGMライブラリ

`public/bgm/` に音源を置くと、書き出し設定でトーン別に選べるようになります。**フォルダに入れるだけ**で一覧に出ます(サーバーの再起動は不要)。

| トーン | 合う案件 |
|---|---|
| 落ち着いた信頼感 | 士業・医療・金融・BtoB SaaS |
| 明るい・軽快 | 小売・飲食・教育・採用 |
| 先進的・テック | IT・製造DX・スタートアップ |
| あたたかい・人物中心 | 介護・保育・地域密着・採用 |
| 力強い・前進 | 建設・物流・営業・成長企業 |

曲名・トーン・想定業種は `public/bgm/catalog.json` に書きます(任意)。**置き方と、Sunoで曲を作るときのプロンプト18曲分は [`public/bgm/README.md`](public/bgm/README.md) にまとめてあります。**

### 音の作り込み(自動で処理されます)

- **尺に合わせて自動ループ** — 曲が短くても動画の長さまで繰り返します。頭1.5秒フェードイン、終わり2.5秒フェードアウト
- **曲ごとの音量差を吸収** — 書き出し前に音源のラウドネスを実測し、基準(-16 LUFS)に揃える固定ゲインを掛けます。**曲を差し替えても同じ音量感**になり、「この曲だとBGMが聞こえない」が起きません
- **話し声に合わせた自動音量ダウン(ダッキング)** — 声が鳴っている間だけBGMが約10dB下がります(サイドチェイン)。声とBGMがぶつかって聞き取りにくくなるのを防ぎます。書き出し設定でオフにもできます

### 音源の権利について

このツールは音源を同梱・配布しません。**権利処理済みの音源をご用意ください。**

生成AIで作った曲を使う場合は、そのサービスの規約で**商用利用が許可されているプラン**かを必ず確認してください(多くのサービスは無料プランを非商用に限定しています)。また、AI生成音源は**著作権が発生しない扱いになるのが一般的**なため、納品先に著作権を譲渡することはできません。「納品物の著作権はすべて発注者に帰属する」型の契約書を使っている場合は、BGMを除外する条項が必要になります。

出所を後から説明できるよう、`catalog.json` の `note` に**生成日・使ったサービス・プラン**を残しておくことを勧めます。

## 出力

- **MP4 / H.264 + AAC**(faststart 付きなので、Webに置いてもすぐ再生が始まります)
- SNS投稿用のキャプションとハッシュタグ

## 動作の前提

- **ffmpeg は npm の依存に同梱**しているため、別途インストールする必要はありません(`npm install` だけで入ります)
- テロップの日本語フォントは OS 標準のもの(Windows: 游ゴシック/メイリオ、macOS: ヒラギノ、Linux: Noto Sans CJK)を自動で探します。
  ブランドフォントを使いたい場合は `public/fonts/telop-bold.ttf` に置くか、`.env` の `TELOP_FONT_PATH` で指定してください
- アップロードした素材と書き出し結果は `.work/` に置かれ、**48時間で自動削除**されます

## 処理時間の目安

## Windows でダブルクリック起動する

初回のセットアップが済んでいれば、以降は **`start-app.bat` をダブルクリック**するだけで起動できます。ターミナルを開く必要はありません。

## チームで使う(1台を社内で共有する)

**`start-shared.bat` をダブルクリック**すると、同じ社内ネットワークにいる人が自分のブラウザから使えるようになります。使う人の側でのインストールは不要です。

起動すると、黒い画面に伝えるべきURLが表示されます。2つのツールが同じサーバーから配信されるため、どちらもそのまま共有できます。

```
 他の人には、このURLを伝えてください:  (イーサネット)

   営業コンソール       http://192.168.1.23:3000/console.html
   Indeed 提案スタジオ  http://192.168.1.23:3000/indeed
```

画面の上部にお互いへのリンクがあるので、どちらか一方を伝えれば行き来できます。

外部サービスへの登録も、月額費用もかかりません。APIキーもこの1台に置いた1つで済みます。

**条件**

- 使う人が**同じ社内ネットワーク**にいること(社外・在宅からは使えません)
- 起動した**1台を立ち上げっぱなし**にしておくこと。黒い画面を閉じると全員使えなくなります
- 初回に Windows のファイアウォールが確認を出したら**「アクセスを許可する」**を選ぶこと。許可しないと他の人から見えません

**パスワードをかける場合**

`.env` に `BASIC_AUTH_PASSWORD` を書くと、`middleware.ts` がすべてのページとAPIをブラウザ標準のBasic認証で保護します。社内ネットワーク内だけなら省略しても構いませんが、**インターネットに公開する場合は必須**です。未設定だと素通しになり、URLを知った第三者にAPIを使われて課金されます(ローカル開発で毎回聞かれないよう、未設定時は無効になる仕様です)。

**環境変数の一覧**

| 変数 | 要否 | 内容 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 必須 | Anthropic APIキー |
| `BASIC_AUTH_PASSWORD` | 公開時は必須 | 入口のパスワード |
| `BASIC_AUTH_USER` | 任意 | ユーザー名(省略時は `team`) |
| `ANTHROPIC_MODEL` | 任意 | 省略時は `claude-opus-5` |
| `OPENAI_API_KEY` | 任意 | AI画像生成を使う場合 |

**営業コンソールとの連携**

共有で使う場合は、営業コンソールの「連携先」欄に共有用のURL(`http://192.168.x.x:3000/indeed`)を入れてください。引き継ぎURLがその宛先で作られます。

## インターネットに公開する(Vercel の無料枠)

PCを起動しておく必要がなく、在宅や外出先からも使えます。無料枠で動きます。

**なぜ動くのか**

生成は3段階に分かれており、**段階ごとに別のリクエスト**として呼び出します(順番は画面側が管理)。1回あたり1〜2分に収まるため、サーバーレスの実行時間制限に収まります。`app/api/indeed/route.ts` の `maxDuration = 300` がその上限です。

```
① strategy(戦略)  →  ② jobpost(原稿) と ③ visual(ビジュアル・運用) を並列
```

**手順**

1. [vercel.com](https://vercel.com) に GitHub アカウントでサインアップ(支払い登録は不要)
2. **Add New → Project** から このリポジトリを選ぶ
3. **Branch** に公開したいブランチを指定する
4. **Environment Variables** に下記を入れる
5. **Deploy** を押す。数分で `https://＜プロジェクト名＞.vercel.app` が発行される
6. `/indeed` を開き、パスワードを入力して動作を確認する
7. 営業コンソールの「連携先」欄に `https://＜ドメイン＞/indeed` を入れる

**公開するときはパスワードが必須です。** `BASIC_AUTH_PASSWORD` が未設定だと素通しになり、URLを知った第三者にAPIを使われて課金されます。

チームには **URL・ユーザー名・パスワード** の3つを伝えれば、あとはブラウザだけで使えます。

## うまく動かないとき

```bash
node check-key.js
```

`.env` の書き方、APIキーの有効性、実際に使うモデルで生成できるか、その所要時間までを診断します。**APIキーの中身は表示しない**ので、結果はそのまま共有できます。

## 使い方のコツ

- **企業HPのURL**: トップページのURLを入れると、AIが事業内容・トーンを自動分析します
- **企業イメージ**: ターゲット層・ブランドの雰囲気・強みを書くほど精度が上がります
- **文言**: キャンペーン情報や期限など、画像に必ず入れたい内容を書いてください
- 生成後もテンプレートを切り替えてデザインの候補を比較できます
- **「✨ AI写真」テンプレート**を選ぶと、ブランドに合わせた写真背景をその場で生成します(OpenAI APIキーが必要。1枚あたり数円〜数十円の従量課金)
- リール動画は「AI写真背景」に切り替えるとKen Burns効果(ゆっくりズーム)付きの写真背景になります
- リールは映像素材があるほど本領を発揮します。Sora のAI動画、またはご自身で撮影した動画のアップロードをおすすめします
- 文字を主役にしたスライド演出の動画がほしいときは、ストーリータブの「🎬 動くストーリー」を使ってください
- OpenAIの新しい画像モデルが出たら `.env` の `OPENAI_IMAGE_MODEL` を変えるだけで切り替えられます

## API ルート

| ルート | 役割 |
|---|---|
| `POST /api/generate` | Instagramコンテンツプランの生成 |
| `POST /api/indeed` | Indeed求人提案の生成(`.env` の `ANTHROPIC_MODEL` でモデルを変更可) |
| `POST /api/background` | OpenAIによる画像生成(`aspect`: `vertical` / `landscape` / 省略時は4:5) |

| `POST /api/video/render` | 編集台本からMP4を書き出す(進捗をNDJSONで返す) |
| `GET /api/video/file` | 素材と書き出し結果の配信(Range対応) |
| `GET /api/video/project` | 案件の読み込み |
| `GET /api/video/bgm` | BGMライブラリの一覧(`public/bgm/` を読む) |
